## Objetivo

Accept `/agent` feedback on an existing agent-generated PR and update that same PR branch instead of creating a new PR for every request

## Alcance y referencias

- `.github/v1/copilot-cli.yml`.
- `scripts/automation/` (nuevo).

Las rutas nuevas o propuestas son entregables del plan, no archivos ya implementados. La configuración de GitHub y los archivos personales requieren acceso y autorización propios.

## Dependencias

- [PK-057](PK-057.md) · Issue autorizada a PR con perfil permitido.
- [PK-059](PK-059.md) · Seguridad de entrada issue/comment.

## Pasos

1. Aceptar /agent en PR solo tras verificar identidad/procedencia de tarea y rama generadas por el sistema.
2. Rechazar forks inicialmente y validar repo/base/head ref/SHA remoto antes de checkout.
3. Reconstruir contexto desde issue, diff, reviews/comentarios, feedback y checks, todo como datos no confiables.
4. Ejecutar mismo perfil y pipeline aislado desde SHA exacto; publicar nuevo commit en la misma rama.
5. Serializar por PR y reconsultar head antes de push; detenerse ante cambios humanos sin sobrescribir.
6. Evaluar resume como optimización con compatibilidad y saneado; mantener reconstrucción como fallback obligatorio.

## Validación y aceptación

- Feedback cambia el mismo PR y activa checks del nuevo head.
- PR ajeno, fork o head cambiado se rechazan sin force-push ni duplicación.
- Funciona sin sesión persistida disponible.
